# v0.3.11 Polish — Part 2: Reachable at Every Address — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make password sign-in work from every address the server answers on — LAN IP, `.local` name, tailnet name — without weakening CSRF protection, and replace the `text/plain` 403 the browser saves as `login.txt` with a page that explains itself.

**Architecture:** SvelteKit's built-in origin check compares the browser's `Origin` against `url.origin`, which adapter-node pins to the `ORIGIN` environment variable — one address, so every other address is refused. That check is turned off and replaced with an equivalent one in `hooks.server.ts` that compares `Origin` against the **request's own `Host`**. Same protection, no single-address assumption. `ORIGIN` survives, narrowed to its other job: the passkey relying party.

**Tech Stack:** SvelteKit 2.70 (inline kit config — this project has no `svelte.config.js`), adapter-node, TypeScript, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-20-v0.3.11-polish-design.md` — Part 2.

## The security rule being implemented

Replacing a security control, so the replacement is stated exactly. A request is refused when **all** of these hold — matching `respond.js:82` except for the final comparison:

1. method is `POST`, `PUT`, `PATCH` or `DELETE`; **and**
2. content type is `application/x-www-form-urlencoded`, `multipart/form-data` or `text/plain` (the three a browser can send cross-origin without a preflight); **and**
3. the `Origin` header is absent, **or** its host differs from the request's own host.

**Host, not full origin.** Scheme is deliberately not compared: the app always speaks HTTP and learns about TLS only from a proxy header that a plain LAN deployment does not have. Comparing hosts keeps the property that matters — a page on `evil.com` cannot post to your ledger, because its `Origin` names `evil.com` while the `Host` names yours. What it gives up is protection against an attacker who can already forge `Host` or terminate TLS, which for a LAN or tailnet deployment means they are already inside.

**`X-Forwarded-Host` is honoured before `Host`,** because behind the Tailscale sidecar the browser's `Origin` names the tailnet address and that is the header carrying it.

```
// SPDX-License-Identifier: PolyForm-Noncommercial-1.0.0
import { describe, expect, it } from 'vitest';
import { sameSiteFormPost } from '$lib/server/csrf';

const post = (headers: Record<string, string>, method = 'POST') =>
	new Request('http://continuum.local/login', {
		method,
		headers: { 'content-type': 'application/x-www-form-urlencoded', ...headers },
		body: 'a=1'
	});

describe('sameSiteFormPost', () => {
	it('allows a form post whose origin matches the host it was sent to', () => {
		expect(sameSiteFormPost(post({ origin: 'http://continuum.local', host: 'continuum.local' }))).toBe(true);
	});

	it('allows the same address reached by IP or by name — the whole point', () => {
		expect(sameSiteFormPost(post({ origin: 'http://192.168.1.40', host: '192.168.1.40' }))).toBe(true);
		expect(sameSiteFormPost(post({ origin: 'http://localhost', host: 'localhost' }))).toBe(true);
		expect(sameSiteFormPost(post({ origin: 'https://continuum.tail1234.ts.net', host: 'continuum.tail1234.ts.net' }))).toBe(true);
	});

	it('allows a port, as long as both carry it', () => {
		expect(sameSiteFormPost(post({ origin: 'http://localhost:4173', host: 'localhost:4173' }))).toBe(true);
	});

	it('refuses a cross-site form post', () => {
		expect(sameSiteFormPost(post({ origin: 'https://evil.com', host: 'continuum.local' }))).toBe(false);
	});

	it('refuses a form post carrying no origin at all', () => {
		expect(sameSiteFormPost(post({ host: 'continuum.local' }))).toBe(false);
	});

	it('prefers x-forwarded-host, which is what a proxy puts the browser address in', () => {
		expect(
			sameSiteFormPost(
				post({
					origin: 'https://continuum.tail1234.ts.net',
					host: 'localhost:3000',
					'x-forwarded-host': 'continuum.tail1234.ts.net'
				})
			)
		).toBe(true);
	});

	it('leaves safe methods alone', () => {
		expect(sameSiteFormPost(post({ origin: 'https://evil.com', host: 'x' }, 'GET'))).toBe(true);
		expect(sameSiteFormPost(post({ origin: 'https://evil.com', host: 'x' }, 'HEAD'))).toBe(true);
	});

	it('leaves non-form content types alone — those need CORS, which is its own gate', () => {
		const json = new Request('http://continuum.local/api/v1/x', {
			method: 'POST',
			headers: { 'content-type': 'application/json', origin: 'https://evil.com', host: 'continuum.local' },
			body: '{}'
		});
		expect(sameSiteFormPost(json)).toBe(true);
	});

	it('refuses a malformed origin rather than trusting it', () => {
		expect(sameSiteFormPost(post({ origin: 'not a url', host: 'continuum.local' }))).toBe(false);
	});
});
```
