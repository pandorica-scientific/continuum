# v0.4.3 Tax Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tax statement holds many documents of stated kinds, and the Tax screen is rebuilt around the year rather than the filer.

**Architecture:** `tax_statement` joins the `entity` supertype so attachments live in the existing generic `document_link` table rather than a new join table. Attachment kind is not stored — it derives the document's name and applies a tag. The screen regroups on year, converts to one display currency at year-end rates while keeping filed figures native, and replaces six charts with one.

**Tech Stack:** SvelteKit 2 (Svelte 5 runes), Drizzle ORM, Postgres, Vitest, embedded-postgres for integration tests.

**Spec:** `docs/superpowers/specs/2026-08-23-v0.4.3-tax-design.md`
**Design handoff:** `docs/superpowers/specs/2026-08-23-tax-tab-handoff/README.md`

## Global Constraints

- **Branch:** `v0.4.3-tax`. Already created and checked out.
- **Never create a git commit.** The user makes every commit. Where a task's final step says "commit", stage nothing and instead report that the task is ready to commit. This overrides the commit steps this plan's format would otherwise imply.
- **Schema is additive-only** (v0.3.9 lock). No table dropped, no column retyped, no column removed.
- **`drizzle/` holds exactly one migration file**, `0000_baseline.sql`. Schema changes are folded into it. `tests/integration/baseline-migration.test.ts:38` enforces this and must keep passing unchanged.
- **Money is `bigint` minor units + a currency code.** Never a float, never a fixed `100`. Use `minorDigits()` / `formatMinor()` / `toMajor()` from `src/lib/money.ts`.
- **No raw geometry or type values in CSS.** `eslint-rules/no-raw-geometry.js` fails the build. Every size, radius, space and font-size resolves a `--*` token from `src/lib/styles/app.css`.
- **No chart library.** The product draws its own SVG.
- **SVG attributes do not resolve `var()`.** Set `fill`, `stroke` and `stop-color` through `style`, never as attributes. `url(#id)` references are fine as attributes.
- **No animation.** The product has effectively none.
- **CHANGELOG entries are one sentence each**, following the 0.4.0–0.4.2 format.
- **Emoji are the icon system.** No icon files.
- Run `npm run test`, `npm run lint` and `npm run check` before declaring any task done.

### Task 2: Fix the backup dump's generated-column bug

**Files:**

- Modify: `src/lib/server/backup/dump.ts:74-78`
- Test: `tests/integration/backup-round-trip.test.ts` (create)

Every backup taken to date is unrestorable. `dump.ts` lists each table's columns from `information_schema.columns` without filtering, so it names `entity_kind` — the `GENERATED ALWAYS … STORED` column the entity supertype puts on eleven tables. `COPY … TO STDOUT` omits generated columns from the data, so the header is one column wider than every row, and Postgres rejects the header outright.

Task 4 needs a restorable backup, so this comes before it.

**Interfaces:**

- Consumes: `dumpDatabase()` from `src/lib/server/backup/dump.ts`, existing signature `(): Promise<string>` — unchanged.
- Produces: nothing new. A dump whose header matches its rows.

// SPDX-License-Identifier: PolyForm-Noncommercial-1.0.0
// A dump nobody has ever read back is a dump nobody knows restores. The unit
// suite covers ordering and policy; this covers the only thing that matters.
import { afterAll, beforeAll, describe, expect, it } from 'vitest';
import { rowId } from '../row-id';
import * as schema from '$lib/server/db/schema';
import { ALL_MIGRATIONS, startPostgres, type Harness, type TestDb } from './harness';

let harness: Harness;
let testDb: TestDb;

const PERSON = rowId('person-a');
const SUBJECT = rowId('subject-a');

beforeAll(async () => {
	harness = await startPostgres('backup-round-trip', { max: 1 });
	testDb = harness.db;
	await harness.applyMigrations(ALL_MIGRATIONS);
}, 180_000);

afterAll(async () => {
	await harness?.stop();
});

describe('a dump restores into the schema it came from', () => {
	it('emits a column list the rows actually match, for entity-registered tables', async () => {
		await testDb.insert(schema.person).values({ id: PERSON, name: 'Person A', initials: 'PA' });
		await testDb.insert(schema.subject).values({ id: SUBJECT, name: 'Car', emoji: '🚗' });

		// What dumpDatabase builds for one table, built the same way.
		const cols = await harness.sql<{ column_name: string }[]>`
			select column_name from information_schema.columns
			where table_schema = 'public' and table_name = 'person'
			  and is_generated = 'NEVER'
			order by ordinal_position`;

		// entity_kind is GENERATED ALWAYS; COPY TO STDOUT never emits it, so a
		// header naming it can only ever be one column too wide.
		expect(cols.map((c) => c.column_name)).not.toContain('entity_kind');

		const chunks: Buffer[] = [];
		const readable = await harness.sql`copy person to stdout`.readable();
		for await (const chunk of readable) chunks.push(chunk as Buffer);
		const fields = Buffer.concat(chunks).toString('utf8').trim().split('\n')[0].split('\t');

		expect(fields.length).toBe(cols.length);
	});

	it('reloads every row it wrote out', async () => {
		const colsFor = async (table: string) => {
			const rows = await harness.sql<{ column_name: string }[]>`
				select column_name from information_schema.columns
				where table_schema = 'public' and table_name = ${table}
				  and is_generated = 'NEVER'
				order by ordinal_position`;
			return rows.map((r) => `"${r.column_name}"`).join(', ');
		};

		const copyOut = async (table: string) => {
			const chunks: Buffer[] = [];
			const readable = await harness.sql`copy ${harness.sql(table)} to stdout`.readable();
			for await (const chunk of readable) chunks.push(chunk as Buffer);
			return Buffer.concat(chunks).toString('utf8');
		};

		const personData = await copyOut('person');
		const personCols = await colsFor('person');

		await harness.sql`delete from person`;
		expect(await testDb.select().from(schema.person)).toHaveLength(0);

		const writable = await harness.sql`
			copy person (${harness.sql.unsafe(personCols)}) from stdin`.writable();
		writable.write(Buffer.from(personData));
		await new Promise<void>((resolve, reject) => {
			writable.on('finish', () => resolve());
			writable.on('error', reject);
			writable.end();
		});

		const restored = await testDb.select().from(schema.person);
		expect(restored).toHaveLength(1);
		expect(restored[0].name).toBe('Person A');
	});
});
```

/**
 * What a file attached to a statement actually is.
 *
 * Not a stored column. The kind picks the document's name and the tag applied
 * to it — both things the document aggregate already takes — so a household can
 * filter every broker report across every year without a schema change.
 */
export const ATTACHMENT_KINDS = [
	{ key: 'statement', label: 'Statement', noun: 'tax statement', tag: 'tax statement' },
	{
		key: 'employer',
		label: 'Employer earnings report',
		noun: 'employer earnings report',
		tag: 'employer report'
	},
	{
		key: 'broker',
		label: 'Broker earnings report',
		noun: 'broker earnings report',
		tag: 'broker report'
	},
	{ key: 'other', label: 'Other', noun: 'tax document', tag: 'tax' }
] as const;

export type AttachmentKind = (typeof ATTACHMENT_KINDS)[number]['key'];

/** A key off a form is whatever the browser sent; an unknown one files as other. */
export function attachmentKind(key: string): (typeof ATTACHMENT_KINDS)[number] {
	return ATTACHMENT_KINDS.find((k) => k.key === key) ?? ATTACHMENT_KINDS[3];
}

/**
 * What a filed document is called on the Tax shelf.
 *
 * Derived from the statement and the kind, not typed again: the name a document
 * is found by should say the same thing the statement says, and a second
 * free-text field would be free to disagree with it.
 *
 * `filename` is appended only when the caller already knows the derived name
 * collides with one linked to the same statement — two broker reports in one
 * year are two files, and a name that identifies neither identifies nothing.
 */
export function statementDocumentName(
	year: number,
	country: string,
	kind: AttachmentKind = 'statement',
	filename?: string
): string {
	const base = `${year} ${country.trim().toUpperCase()} ${attachmentKind(kind).noun}`;
	const suffix = filename?.trim();
	return suffix ? `${base} · ${suffix}` : base;
}
```

 * Names collide when two files of one kind land in one year, so a name already

	statementId: string,
	personId: string,
	year: number,
	country: string,
	attachments: StatementAttachment[],

): Promise<void> {

		.select({ name: document.name })
		.from(documentLink)

		.where(eq(documentLink.targetId, statementId));

	for (const attachment of attachments) {
		const plain = statementDocumentName(year, country, attachment.kind);
		const name = taken.has(plain)
			? statementDocumentName(year, country, attachment.kind, attachment.original)
			: plain;

				// documents screen builds no column and the paper goes missing

				accountIds: [],

 * still filed against the person — deleting filed paperwork is the documents

	statementId: string,
	documentId: string,
	handle: Db = db

		.delete(documentLink)
		.where(and(eq(documentLink.targetId, statementId), eq(documentLink.documentId, documentId)))
		.returning({ documentId: documentLink.documentId });

	const [rows, lines, people] = await Promise.all([
		db.select().from(taxStatement),
		db.select().from(taxStatementLine),
		db.select({ id: person.id, name: person.name }).from(person)
	]);

	// document_link would also return every document filed against a person,
	// a property or a transaction — the far end of a link is any entity.
	const statementIds = rows.map((r) => r.id);
	const attachments = statementIds.length
		? await db
				.select({
					statementId: documentLink.targetId,
					id: document.id,
					name: document.name,
					ext: document.ext,
					file: document.storedName
				})
				.from(documentLink)
				.innerJoin(document, eq(document.id, documentLink.documentId))
				.where(inArray(documentLink.targetId, statementIds))
				.orderBy(document.addedOn)
		: [];

	const personName = new Map(people.map((p) => [p.id, p.name]));
	return rows.map((r) => ({
		...r,
		personName: personName.get(r.personId) ?? '—',
		attachments: attachments
			.filter((a) => a.statementId === r.id)
			.map((a) => ({ id: a.id, name: a.name, ext: a.ext, file: a.file })),
		lines: lines
			.filter((l) => l.statementId === r.id)
			.sort((a, b) => a.sort - b.sort)
			.map((l) => ({ label: l.label, amountMinor: l.amountMinor }))
	}));

/**
 * A figure short enough to scan down a column: `4.37M`, `41k`, `368`.
 *
 * No currency symbol — the column header carries it, and repeating it on every
 * cell is noise in a grid whose whole purpose is comparing one number to the
 * one below it. The thresholds are decimal facts, not policy.
 */
export function compactMinor(amountMinor: bigint, currency: string): string {
	const major = toMajor(amountMinor, currency);
	const magnitude = Math.abs(major);
	const sign = major < 0 ? '-' : '';
	if (magnitude >= 1_000_000) return `${sign}${(magnitude / 1_000_000).toFixed(2)}M`;
	if (magnitude >= 1_000) return `${sign}${Math.round(magnitude / 1_000)}k`;
	return `${sign}${Math.round(magnitude)}`;
}

	return BigInt(Math.round(Number(amount) * rate));
};

export interface YearCountry {
	country: string;
	/** Converted to the display currency, minor units. */
	grossMinor: bigint;
	taxMinor: bigint;
	ratePct: number | null;
	/** The filed figures, untouched — for the expansion and the hover readout. */
	native: { currency: string; grossMinor: bigint; taxMinor: bigint }[];
}

export interface YearRow {
	year: number;
	/** One entry per jurisdiction that filed in this year. */
	byCountry: YearCountry[];
	grossMinor: bigint;
	taxMinor: bigint;
	ratePct: number | null;
}

/**
 * Statements regrouped on the axis they are READ on.
 *
 * Grouping by person·country is the axis they were entered on: a household that
 * has filed in four jurisdictions over eight years sees one year in three
 * separate places, and "what did 2024 cost me" is a question the layout cannot
 * answer.
 *
 * Conversion happens at YEAR END, never at today's rate. A yearly statement is
 * not a dated transaction; using today's rate for a 2018 filing restates
 * history every time the rate table updates.
 */
export function taxByYear(
	statements: StatementLike[],
	displayCurrency: string,
	convert: (amount: bigint, from: string, to: string, day: string) => bigint,
	personId?: string
): YearRow[] {
	const wanted = personId ? statements.filter((s) => s.personId === personId) : statements;

	const years = new Map<number, Map<string, YearCountry>>();
	for (const s of wanted) {
		const day = `${s.year}-12-31`;
		const countries = years.get(s.year) ?? new Map<string, YearCountry>();
		const existing = countries.get(s.country) ?? {
			country: s.country,
			grossMinor: 0n,
			taxMinor: 0n,
			ratePct: null,
			native: []
		};
		existing.grossMinor += convert(s.grossIncomeMinor, s.currency, displayCurrency, day);
		existing.taxMinor += convert(s.taxPaidMinor, s.currency, displayCurrency, day);
		existing.native.push({
			currency: s.currency,
			grossMinor: s.grossIncomeMinor,
			taxMinor: s.taxPaidMinor
		});
		countries.set(s.country, existing);
		years.set(s.year, countries);
	}

	return [...years.entries()]
		.sort((a, b) => a[0] - b[0])
		.map(([year, countries]) => {
			const byCountry = [...countries.values()]
				.map((c) => ({ ...c, ratePct: effectiveRatePct(c.grossMinor, c.taxMinor) }))
				.sort((a, b) => a.country.localeCompare(b.country));
			const grossMinor = byCountry.reduce((sum, c) => sum + c.grossMinor, 0n);
			const taxMinor = byCountry.reduce((sum, c) => sum + c.taxMinor, 0n);
			return {
				year,
				byCountry,
				grossMinor,
				taxMinor,
				ratePct: effectiveRatePct(grossMinor, taxMinor)
			};
		});
}

/**
 * Lifetime rate, weighted by income — totalTax / totalGross over the whole
 * record, not a mean of the yearly percentages. A mean gives a 2018 filing of
 * €924 the same vote as a 2025 filing of €174 000, which is wrong by two orders
 * of magnitude.
 */
export function blendedRatePct(rows: YearRow[]): number | null {
	const gross = rows.reduce((sum, r) => sum + r.grossMinor, 0n);
	const tax = rows.reduce((sum, r) => sum + r.taxMinor, 0n);
	return effectiveRatePct(gross, tax);
}

/**
 * Below this, a filing is too small to be a full year and the cell says so.
 *
 * Five per cent of the median filing rather than an amount: a threshold in
 * money would have to name a currency, and would go stale as the record grows.
 * The median rather than the mean, so one outlier cannot raise the bar that is
 * meant to catch it.
 */
export function flaggedThresholdMinor(rows: YearRow[]): bigint {
	const filings = rows
		.flatMap((r) => r.byCountry.map((c) => c.grossMinor))
		.filter((g) => g > 0n)
		.sort((a, b) => (a < b ? -1 : a > b ? 1 : 0));
	if (filings.length === 0) return 0n;
	const median = filings[Math.floor(filings.length / 2)];
	return median / 20n;
}

/**
 * A posted preference, made safe.
 *
 * The column is jsonb and stores whatever it is handed, so nothing that arrives
 * over the wire is trusted: an unknown mode, a currency nothing can convert, or
 * a person id belonging to no one all fall back rather than being stored.
 */
export function normaliseTaxView(
	body: unknown,
	personIds: string[],
	currencies: string[]
): TaxViewPrefs {
	const fallback: TaxViewPrefs = {
		mode: 'stack',
		currency: currencies[0] ?? 'EUR',
		person: 'both'
	};
	if (typeof body !== 'object' || body === null) return fallback;
	const raw = body as Record<string, unknown>;
	return {
		mode: raw.mode === 'rate' ? 'rate' : 'stack',
		currency:
			typeof raw.currency === 'string' && currencies.includes(raw.currency)
				? raw.currency
				: fallback.currency,
		person:
			typeof raw.person === 'string' && (raw.person === 'both' || personIds.includes(raw.person))
				? raw.person
				: 'both'
	};
}

import { db } from '$lib/server/db';

import { normaliseTaxView } from '$lib/tax';

/**
 * Save how this person left the Tax screen.
 *
 * Written on discrete gestures — a toggle, a filter — and the last write wins.
 * Two tabs belong to the same person, so losing costs one click.
 */
export const PUT: RequestHandler = async ({ request, locals }) => {
	if (!locals.person) error(401, 'Sign in first.');

	let body: unknown;
	try {
		body = await request.json();
	} catch {
		error(400, 'Expected a JSON body.');
	}

	const [people, currencies] = await Promise.all([
		db.select({ id: person.id }).from(person),
		availableCurrencies()
	]);

	const prefs = normaliseTaxView(
		body,
		people.map((p) => p.id),
		currencies
	);
	await db.update(person).set({ taxView: prefs }).where(eq(person.id, locals.person.id));

	// Handing back what was stored lets the screen correct itself when it posted
	// something the server refused.
	return json(prefs);
};
