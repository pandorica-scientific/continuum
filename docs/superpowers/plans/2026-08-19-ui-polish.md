# UI polish backlog

Raised 2026-08-19, after the v0.3.9 cleanup. Small, independent items — no
plan document each, but recorded here so none of them is lost between sessions.

## Tablet

- [ ] **The sidebar scrolls with the page.** It should be fixed, fill the full
      screen height, and stay put while the right-hand panel scrolls under it.
      Today it is in the normal flow, so on a tablet viewport the whole page —
      navigation included — moves together.

- [ ] **Overscroll reveals white.** Pulling down past the top or bottom shows
      the browser's default background rather than the app's, in both dark and
      light. The fix is a background on `html`/`body` (and
      `background-color` on the scroll container), not on a wrapper element —
      the rubber-band area is painted by the document, not by the layout.

## Settings and the sidebar

- [ ] **Surface the self-hosting facts in the side panel, not only in Settings.**
      Version, and what it is running under (Docker or otherwise). Set smaller
      and in a lighter colour than the navigation, so it reads as an instrument
      panel rather than another link.

## General

- [ ] A pass for the same class of issue elsewhere: anything that assumes a
      desktop viewport, and anywhere the page background is painted by a
      wrapper rather than by the document.
